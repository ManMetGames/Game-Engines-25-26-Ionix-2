Ionix Engine Lua API

Full Lua scripting reference for 2025 build (Scripting.cpp + AudioScripting.cpp)

Modules & Hooks

Each Lua script module can implement these lifecycle hooks:

HookDescription
OnStart()Called once at game start.
OnUpdate()Called every frame.
OnShutdown()Called before the game quits.

Use GetModule("name") to get another loaded module instance.

Window

FunctionDescription
Window.get_title()Returns the current window title.
Window.get_width()Returns the window width in pixels.
Window.get_height()Returns the window height in pixels.

Input

FunctionDescription
Input.get_key_up(KeyCode)True if key released this frame.
Input.get_key_down(KeyCode)True if key pressed this frame.
Input.get_key_held(KeyCode)True if key held down.

Available key constants: Keys.ionix_a–Keys.ionix_z, numbers, arrows, space, escape, etc.

FunctionDescription

Mafs.abs(x)Absolute value.

Mafs.max(x, maxVal)Maximum of x and maxVal.

Entity

FunctionDescription
Entity.create_entity()Create a new scene entity.
Entity.get_entity_pos(entity)Get entity position.
Entity.set_entity_pos(entity, x, y)Set entity position.
Entity.add_sprite_component(entity, alias, zOrder)Add sprite component.

UI

UI.draw_label(text, w, h, x, y)Draw label on screen.
UI.draw_button(text, w, h, x, y)Draw button (returns true if clicked).
UI.draw_slider(text, value, w, h, x, y, min, max)Draw slider (returns new value).

Texture

Texture.add_texture(path, alias)Loads a texture file and registers an alias.

Audio

SoundManager

FunctionDescription
SoundManager.GetInstance()Returns singleton SoundManager.
SoundManager:LoadSound(name, path)Loads sound from file.
SoundManager:SetVolume(name, volume)Sets volume (0–1).
SoundManager:GetAudio(name)Returns AudioPlayer for that sound.
SoundManager:GetPlayTime(name)Returns play time info (if supported).

AudioPlayer

AudioPlayer:new(entity, soundName, playOnAwake)Creates AudioPlayer for an entity.
AudioPlayer:Play()Play sound immediately.
AudioPlayer:Play(fadeMs)Play with fade-in (ms).
AudioPlayer:Play(fadeMs, loops)Play with fade and looping.
AudioPlayer:Pause()Pause playback.
AudioPlayer:Resume()Resume paused sound.
AudioPlayer:End()Stop playback completely.
AudioPlayer:IsPlaying()Check if currently playing.
AudioPlayer:PlayOneShot()Play sound once without interrupting others.
AudioPlayer:ChangeVolume(v)Change playback volume.
AudioPlayer:ToggleMute()Toggle mute state.
AudioPlayer.volumeVolume property (0–128).
AudioPlayer.muteBoolean mute flag.
AudioPlayer.clipAssigned clip name/path.
AudioPlayer.playOnAwakeTrue = auto play on creation.
