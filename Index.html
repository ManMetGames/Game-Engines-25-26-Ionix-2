🎮 Engine Function Reference

A quick-access guide for Input, Maths, Vectors, Graphics, and Audio systems.

🕹️ Input

FunctionDescription
IsKeyUp(KeyCode)Checks if the given key is released.
IsKeyDown(KeyCode)Checks if the given key is pressed.
IsKeyHeld(KeyCode)Checks if the given key is continually held down.

🧮 Maths

FunctionDescription
clamp(float input, float min, float max)Restricts input to stay between min and max.
abs(float input)Returns the absolute value of input (makes negatives positive).
min(float input, float min)Ensures input is not less than min.
max(float input, float max)Ensures input is not greater than max.
round(float input)Rounds input to the nearest integer.
log(float input)Returns the logarithm (inverse of exponential) of input.
log_custom(float input, float base)Returns the logarithm of input with a custom base.
square_root(float input)Returns the square root of input.
lerp(float x, float y, float time)Linearly interpolates from x to y over the given time.
mod(float x, float y)Returns the remainder of x divided by y.
div(float x, float y)Returns the whole number result of x divided by y.
sin(float angle)Returns the sine of angle (in radians).
cos(float angle)Returns the cosine of angle (in radians).
tan(float angle)Returns the tangent of angle (in radians).
piReturns the mathematical constant π (3.141592...).

🧩 Vectors

Vector2

FunctionDescription
vector2(float x, float y)Creates a 2D vector.
vector2_xGets the x component of a Vector2 as a float.
vector2_yGets the y component of a Vector2 as a float.
sqr_magnitude_vector2(vector2 input)Returns the squared magnitude of a Vector2.

Vector3

FunctionDescription
vector3(float x, float y, float z)Creates a 3D vector.
vector3_xGets the x component of a Vector3 as a float.
vector3_yGets the y component of a Vector3 as a float.
vector3_zGets the z component of a Vector3 as a float.
sqr_magnitude_vector3(vector3 input)Returns the squared magnitude of a Vector3.

🖼️ Graphics

FunctionDescription
create_sprite(string path, string fileName)Creates an image with the given name from the specified path.
draw_sprite(string fileName, float x, float y, float z, float scale)Draws the given image at the specified position and scale.

🔊 Audio

SoundManager

Controls all sound-related functions.

FunctionDescription
GetInstance()Returns the current SoundManager instance.
LoadSound(string soundName, string soundPath)Loads a sound from the given path and assigns it the given name.
SetVolume(string soundName, float volume)Sets the volume of a sound.
GetAudio(string soundName)Returns the audio clip associated with the name.

AudioPlayer

Manages a specific sound rather than all sounds in the SoundManager.

FunctionDescription
.Play()Plays the assigned sound.
.Play(int fadeTime)Plays the sound with a fade-in over fadeTime milliseconds.
.Pause()Pauses the audio.
.Resume()Resumes playback.
.End()Stops and ends playback.
.IsPlayingReturns a bool indicating if the sound is currently playing.
.ChangeVolume(float volume)Changes the volume of the sound.
.ToggleMute()Toggles mute on/off.
.volumeAn int (0–128) representing the sound volume level.
.muteA bool indicating whether the sound is muted.
.clipSelects a portion of an audio file.
.loopEnables or disables looping for the track.
.playOnAwakeIf true, plays the audio automatically when loaded.
