Lifecycle Hooks

HookDescription
OnStart()Called when the script initializes.
OnUpdate()Called every frame update.
OnShutdown()Called before the application closes.

Window

FunctionDescription
Window.get_title()Returns window title string.
Window.get_width()Window width in pixels.
Window.get_height()Window height in pixels.

Input

FunctionDescription
Input.get_key_down(Keys.code)True if pressed this frame.
Input.get_key_up(Keys.code)True if released this frame.
Input.get_key_held(Keys.code)True if currently held.

Key constants include: Keys.ionix_a–ionix_z, ionix_1–ionix_0, ionix_space, ionix_lctrl, etc.

Mafs.abs(x)Absolute value.
Mafs.round(x)Rounds value.
Mafs.lerp(a, b, t)Linear interpolation.
Mafs.log(x)Natural log.
Mafs.log_10(x)Base-10 log.
Mafs.log_custom(x, base)Custom log base.
Mafs.square_root(x)Square root.
Mafs.sin(x)Sine.
Mafs.cos(x)Cosine.
Mafs.tan(x)Tangent.
Mafs.pi()Returns π.
Mafs.vector2(x, y)Create a 2D vector.
Mafs.vector3(x, y, z)Create a 3D vector.

UI

Audio

SoundManager

SoundManager.GetInstance()Access SoundManager singleton.
SoundManager:LoadSound(name, path)Load WAV file.
SoundManager:SetVolume(name, volume)Set volume (0–1).
SoundManager:GetAudio(name)Get AudioPlayer reference.
SoundManager:GetPlayTime(name)Get current play time.

AudioPlayer

AudioPlayer:new(entity, soundName, playOnAwake)Create AudioPlayer component.
AudioPlayer:Play()Play sound.
AudioPlayer:Play(fadeMs)Play with fade-in.
AudioPlayer:Play(fadeMs, loops)Play with fade and looping.
AudioPlayer:Pause()Pause playback.
AudioPlayer:Resume()Resume playback.
AudioPlayer:End()Stop playback.
AudioPlayer:IsPlaying()Check play state.
AudioPlayer:PlayOneShot()Play sound once.
AudioPlayer:ChangeVolume(value)Adjust volume.
AudioPlayer:ToggleMute()Toggle mute.
AudioPlayer.volumeVolume (0–128).
AudioPlayer.muteMute flag.
AudioPlayer.clipSound clip alias.
AudioPlayer.playOnAwakeAuto play toggle.
