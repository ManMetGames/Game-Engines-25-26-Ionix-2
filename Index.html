Ionix Engine Lua API

Lua scripting reference for the Ionix Engine runtime

Audio

SoundManager

SoundManager.GetInstance()Returns the SoundManager instance.
SoundManager:LoadSound(name, path)Loads a sound file from the given path.
SoundManager:SetVolume(name, volume)Sets the sound volume (0–128).
SoundManager:GetAudio(name)Returns an AudioPlayer for the specified sound.

AudioPlayer

AudioPlayer:new(entity, soundName, playOnAwake)Creates a new AudioPlayer.
AudioPlayer:Play()Plays the assigned sound.
AudioPlayer:Pause()Pauses the sound.
AudioPlayer:Resume()Resumes playback.
AudioPlayer:End()Stops playback completely.
AudioPlayer:IsPlaying()Returns true if the sound is playing.
AudioPlayer:ChangeVolume(volume)Changes the volume level.
AudioPlayer:ToggleMute()Toggles mute on or off.
AudioPlayer.volumeInteger volume property (0–128).
AudioPlayer.muteBoolean mute state.
AudioPlayer.loopEnables or disables looping.
AudioPlayer.playOnAwakeAutomatically plays on creation if true.
