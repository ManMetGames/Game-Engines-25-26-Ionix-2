Ionix Engine Lua API

Callable Lua functions within the Ionix Engine

Window

FunctionDescription
Window.get_title()Returns the window title.
Window.get_width()Returns the window width in pixels.
Window.get_height()Returns the window height in pixels.

Input

FunctionDescription
Input.get_key_up(KeyCode)Checks if a key was released.
Input.get_key_down(KeyCode)Checks if a key was pressed.
Input.get_key_held(KeyCode)Checks if a key is held down.

Key Codes: Keys.ionix_a–Keys.ionix_z, Keys.ionix_space, Keys.ionix_escape, Keys.ionix_return, etc.

Mafs (Maths)

FunctionDescription
Mafs.clamp(x, min, max)Restricts x between min and max.
Mafs.abs(x)Returns the absolute value of x.
Mafs.min(x, minVal)Ensures x ≥ minVal.
Mafs.max(x, maxVal)Ensures x ≤ maxVal.
Mafs.round(x)Rounds to the nearest integer.
Mafs.log(x)Returns the natural logarithm.
Mafs.log_custom(x, base)Returns the logarithm of x with a custom base.
Mafs.square_root(x)Returns the square root of x.
Mafs.lerp(x, y, t)Interpolates between x and y by t.
Mafs.mod(x, y)Returns the remainder of x divided by y.
Mafs.div(x, y)Returns the whole number result of x divided by y.
Mafs.sin(a)Returns the sine of angle a (radians).
Mafs.cos(a)Returns the cosine of angle a (radians).
Mafs.tan(a)Returns the tangent of angle a (radians).
Mafs.pi()Returns the mathematical constant π.

Vectors

Vector2

FunctionDescription
Mafs.vector2(x, y)Creates a 2D vector.
Mafs.vector2_x(v)Returns the X component of the vector.
Mafs.vector2_y(v)Returns the Y component of the vector.
Mafs.sqr_magnitude_vector2(v)Returns the squared magnitude of the vector.

Vector3

FunctionDescription
Mafs.vector3(x, y, z)Creates a 3D vector.
Mafs.vector3_x(v)Returns the X component of the vector.
Mafs.vector3_y(v)Returns the Y component of the vector.
Mafs.vector3_z(v)Returns the Z component of the vector.
Mafs.sqr_magnitude_vector3(v)Returns the squared magnitude of the vector.

Entity

FunctionDescription
Entity.create_entity()Creates a new entity in the current scene.
Entity.get_entity_pos(entity)Returns the entity’s position as Vec2.
Entity.set_entity_pos(entity, x, y)Sets the entity’s position.
Entity.add_sprite_component(entity, alias, zOrder)Adds a sprite component with a texture alias and z-order.

UI

FunctionDescription
UI.draw_label(text, w, h, x, y)Draws a label on the UI.
UI.draw_button(text, w, h, x, y)Draws a button and returns true if clicked.
UI.draw_slider(text, value, w, h, x, y, min, max)Draws a slider and returns the new slider value.

Texture / Graphics

FunctionDescription
Texture.add_texture(filePath, alias)Loads a texture from file and assigns it an alias.

Audio

SoundManager

FunctionDescription
SoundManager.GetInstance()Returns the SoundManager instance.
SoundManager.LoadSound(name, path)Loads a sound from a file.
SoundManager.SetVolume(name, volume)Sets the volume for a sound.
SoundManager.GetAudio(name)Retrieves the AudioPlayer for a sound.

AudioPlayer

Function / PropertyDescription
.Play()Plays the sound.
.Play(fadeTime)Plays with fade-in (milliseconds).
.PlayOneShot()Plays the sound once immediately.
.Pause()Pauses playback.
.Resume()Resumes playback.
.End()Stops playback completely.
.IsPlayingReturns true if the sound is playing.
.ChangeVolume(v)Changes volume (0–128).
.ToggleMute()Toggles mute on or off.
.loopEnables or disables looping.
.muteReturns or sets mute state.
.clipSelects a portion of the audio file.
.playOnAwakeAutomatically plays when loaded if true.
