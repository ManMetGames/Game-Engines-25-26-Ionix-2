A funny Lua api for our game

Window

FunctionDescription
Window.get_title()Returns the current window title.
Window.get_width()Returns the window width in pixels.
Window.get_height()Returns the window height in pixels.

Input

FunctionDescription
Input.get_key_up(KeyCode)Returns true if the key was released this frame.
Input.get_key_down(KeyCode)Returns true if the key was pressed this frame.
Input.get_key_held(KeyCode)Returns true if the key is being held down.

Available key constants: Keys.ionix_a–Keys.ionix_z, Keys.ionix_space, Keys.ionix_escape, Keys.ionix_return, etc.

Mafs (Maths)

FunctionDescription
Mafs.clamp(x, min, max)Clamps x between min and max.
Mafs.abs(x)Returns the absolute value of x.
Mafs.min(x, minVal)Ensures x ≥ minVal.
Mafs.max(x, maxVal)Ensures x ≤ maxVal.
Mafs.round(x)Rounds x to the nearest integer.
Mafs.log(x)Returns the natural logarithm of x.
Mafs.log_custom(x, base)Returns the logarithm of x with a custom base.
Mafs.square_root(x)Returns the square root of x.
Mafs.lerp(x, y, t)Linearly interpolates between x and y.
Mafs.mod(x, y)Returns the remainder of x divided by y.
Mafs.div(x, y)Returns the whole-number division of x by y.
Mafs.sin(a)Returns the sine of a in radians.
Mafs.cos(a)Returns the cosine of a in radians.
Mafs.tan(a)Returns the tangent of a in radians.
Mafs.pi()Returns the mathematical constant π.

Vectors

Mafs.vector2(x, y)Creates a 2D vector.
Mafs.vector2_x(v)Gets the X component of a vector.
Mafs.vector2_y(v)Gets the Y component of a vector.
Mafs.sqr_magnitude_vector2(v)Returns the squared magnitude.

Vector3

Mafs.vector3_y(v)Gets the Y component.
Mafs.vector3_z(v)Gets the Z component.

Entity

Entity.create_entity()Creates a new entity.
Entity.get_entity_pos(entity)Returns the entity’s position.
Entity.set_entity_pos(entity, x, y)Sets the entity’s position.
Entity.add_sprite_component(entity, alias, zOrder)Adds a sprite component.

UI

UI.draw_label(text, w, h, x, y)Draws a label.
UI.draw_button(text, w, h, x, y)Draws a button and returns true if clicked.
UI.draw_slider(text, value, w, h, x, y, min, max)Draws a slider and returns new value.

Texture

Texture.add_texture(path, alias)Loads a texture and assigns an alias.

Audio

SoundManager

SoundManager.GetInstance()Returns the SoundManager instance.
SoundManager:LoadSound(name, path)Loads a sound from file.
SoundManager:SetVolume(name, volume)Sets the volume for a sound.
SoundManager:GetAudio(name)Returns an AudioPlayer instance.

AudioPlayer

AudioPlayer:new(entity, soundName, playOnAwake)Creates a new AudioPlayer.
AudioPlayer:Play()Plays the assigned sound.
AudioPlayer:Pause()Pauses playback.
AudioPlayer:Resume()Resumes playback.
AudioPlayer:End()Stops playback.
AudioPlayer:IsPlaying()Returns true if the sound is playing.
AudioPlayer:ChangeVolume(volume)Changes the sound’s volume.
AudioPlayer:ToggleMute()Toggles mute on/off.
AudioPlayer.volumeVolume property (0–128).
AudioPlayer.muteBoolean mute flag.
AudioPlayer.loopBoolean to loop playback.
AudioPlayer.playOnAwakePlays automatically on load if true.
